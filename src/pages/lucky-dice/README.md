# Lucky Dice

## Upgrades

1. More Dice: More dice to roll
2. Faster roll: gives result faster
3. Less numbers: All die have less options to roll
4. Higher payout: more points per lucky roll
5. Streak Multiplier: multiplied points for sequential lucky rolls
6. Your lucky number (1): choose a new lucky number
7. Stats (1): unlock stats page
8. Hard Mode (1): Restart game in hard mode
9. Winner (1): it's finally over...

## Achievements

### Core [Unlocks Upgrade]
- Curiosity [1]: roll 10 times
- Impatient [2]: try to roll a die that is already rolling
- Unlucky [3]: roll a failure 10 times in a row
- Locked in [4]: roll lucky number 15 times
- Gambler[5]: Roll lucky number twice in a row
- Explorer [6]: Roll each number once
- Interest [7]: roll 100 times 
- Rich [8]: save up 100 points
- Good luck, you need it [9]: unlock hard mode

### Extra
- D1: only the lucky number is available to roll
- Rigged: make the lucky number unavailable to roll
- Forgetful: no rolling for two minutes
- Hoarder: buy all 7 upgrades at least once (no hard mode)
- Addiction: roll 500 times
- Dizzy: have 3 dice rolling at the same time
- Quizzical: view the info tab
- Spray n' Pray: miss a die roll
- Classic: change to pips
- On a Roll: roll 3 sequential numbers in order
- Dice Master: buy the "winner" upgrade
- The Brick: learn 2 search
